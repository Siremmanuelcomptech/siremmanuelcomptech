# Sir. Emmanuel CompTech — Advanced E-commerce Cyber Services Website

## Included
- Multi-page responsive website: Home, Services, Service Shop, About, Contact
- User-provided Sir Emmanuel photo used as the visual brand/profile image
- Searchable 20+ category service catalogue
- Add-to-request cart using localStorage
- WhatsApp request/quotation flow
- Email contact
- Animated hero graphics and service showcase
- Mobile responsive design
- SEO title/description basics
- All supplied service prices included as suggested service/assistance fees

## Publish
Upload the entire folder to GitHub, Netlify, Vercel or another web host. Keep the `assets` folder beside the HTML files.

## Important
The "e-commerce" flow currently handles service selection and WhatsApp confirmation rather than collecting online payments. A real M-Pesa/Paystack/Stripe checkout can be connected later using the appropriate business payment credentials.
